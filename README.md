# PHP Calculator

A small, single-file PHP example that adds two numbers and displays the result in an HTML page. It is intended as a beginner-friendly demonstration of PHP functions, arithmetic, and embedding PHP in HTML.

## Why use this project?

- See a complete PHP-to-HTML example in [`index.php`](index.php).
- Follow how a function stores two values, adds them, and prints the result.
- Run it locally with PHP; the project has no external dependencies.

The example uses the hard-coded values `10` and `25`, so it displays their sum, `35`. It is not an interactive calculator.

## Get started

### Requirements

- PHP installed and available as the `php` command.

### Run locally

From the project directory, start PHP's built-in development server:

```sh
php -S localhost:8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The page displays:

```text
The sum of 10 and 25 is 35.
```

Stop the server with `Ctrl+C`.
